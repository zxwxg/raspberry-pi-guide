Basics

A small, cheap, low-power computer on a single board that runs Linux and can also control electronics through its GPIO pins.

No. You can browse, watch video, write documents and use it like any PC. Then, when you are curious, Python and Scratch are installed and ready. Most people learn more in their first month of owning a Pi than in a year of reading about programming.

  • Absolute beginner, tight budget: Pi 4 · 4 GB ($55 + $40 of extras).
  • Want a real desktop and future-proof: Pi 5 · 8 GB ($80).
  • Just electronics and motors: Pico 2 ($5) plus a breadboard kit.
  • Kids or a school: Pi 500 kit ($120) — nothing to assemble wrongly.
  • Zero-effort home server: Pi 5 · 4 GB + NVMe if you plan Docker, or a Zero 2 W for one small job.

About 20–30 minutes if everything is in the box: install Raspberry Pi Imager, write the OS to the card (3–5 min), set username/Wi-Fi/SSH in Imager's settings window, insert the card, power on, wait for the first boot to finish. With the Desktop edition (x86) in a virtual machine, add 15 minutes.

Internet: needed for updates and packages, not for running most projects. Monitor/keyboard: only for the very first configuration — and even that is optional, because Imager can pre-set Wi-Fi and SSH so you can control the Pi persistently from your normal computer. That mode is called headless.

Yes — that is exactly what most media-centre and retro-gaming builds do. Any HDMI TV works. For a Pi 4/5 remember you need a micro-HDMI to HDMI cable, not a normal one.

Buying & money

Import duty, VAT/local sales tax, shipping and local distributor margins. In some countries the same 8 GB Pi 5 costs 25–40 % more than the US list price. Compare the total delivered price from a local approved reseller against importing directly — importing looks cheaper until customs adds its share.

Kits usually win on total cost because they bundle shipping and bundle accessories at volume prices. Parts separately win when you already own a keyboard, monitor, microSD cards or a suitable power supply. Rule: count the accessories you actually need ($12 PSU, $14 SD, $9 cable, $5 cooler) before deciding.

Often not, and the accessories are worse. The three classic scams are: rebadged older models sold as new, power supplies that claim 5 A but deliver 3 A, and microSD cards with fake capacity. Buy boards from the official reseller list, and verify any card you buy with H2testw or F3.

No. Raspberry Pi OS, the Imager tool, Ubuntu, LibreELEC, Home Assistant and essentially every library you will use are free and open source. There is no licence, no subscription and no watermark. The only paid things are optional: extra hardware, and third-party services you might choose to connect (VPN, cloud backup, streaming).

Four items — nothing else:

  • Board — from $35
  • Power supply — $8
  • microSD card — $8
  • Any HDMI screen + USB keyboard/mouse you already own

That is about $51 for a real, working computer — and adding a case plus a cooler is only $10–$15 more.

Software & operating systems

  • Raspberry Pi OS (Debian-based, recommended) — Desktop or Lite
  • Ubuntu Server/Desktop ARM64 — good for developers
  • Debian and Alpine — minimal servers
  • LibreELEC / OSMC — Kodi media centres
  • RetroPie / Batocera / Lakka — retro gaming
  • Home Assistant OS — smart-home appliance
  • DietPi — tiny, ultra-light, menu-driven setup
  • OpenWrt / pfSense-class — network appliance duties

You can also write a custom image with pi-gen, or use Docker on top of any of them.

Windows 11 on ARM can be installed on a Pi 4/5 but it is unofficial, slow, needs a lot of fiddling and has no GPU acceleration. Windows 10 IoT Core is discontinued. If you need Windows, use a cheap x86 mini-PC instead — the Pi is not the right tool. Linux is where the Pi shines.

There are community Android builds (LineageOS, KonstaKANG) that work on the Pi 4/5, and they are fine for experimentation, kiosk displays and some apps. They are not certified, many apps lack ARM support, and streaming apps with DRM rarely work. Expect a project, not a phone replacement.

Yes — it is Debian with Raspberry Pi's tooling. Every Linux skill transfers both ways: if you learn apt, systemd, permissions and networking on a Pi, you can administer a real server. The only additions are hardware-specific tools like raspi-config, vcgencmd, rpicam and the GPIO libraries.

Yes, in three ways: (1) move the microSD/NVMe across (it boots, since the OS is portable between Pi models), (2) restore a full disk image you made earlier with dd or Win32DiskImager, or (3) keep your configuration in docker-compose.yml files and an Ansible/script setup so a new board is a fresh install plus one command.

Hardware & limits

Emulated games: yes, up to roughly PlayStation 1 reliably on a Pi 4, with N64/Dreamcast/PSP on a Pi 5. Native games: only lightweight 2D indie titles and open-source games (SuperTuxKart, Minetest). Modern 3D games: no. There is no discrete GPU and no x86 game ecosystem.

Yes, surprisingly well. A Pi 5 with 8 GB runs a Java PaperMC server for roughly 4–8 players with modest view distance, and a Bedrock server runs fine too. Use an NVMe or USB SSD, not a microSD, and expect to tune memory settings. Large public servers with mods and plugins are out of scope.

Local small models: yes. With Ollama on a Pi 5 (8–16 GB) you can run 1–3 B parameter models for basic chat, and Whisper for speech-to-text. With the AI HAT+ (13/26 TOPS) you get good real-time computer vision. Training models: no. Also remember you can always just call a cloud API for the heavy lifting — the Pi is perfectly suited to being the device that uses AI.

Not directly — 3.5" drives need 12 V, which the Pi does not supply. Use a powered USB enclosure or an external power supply for the disk. 2.5" USB drives and SSDs generally work if your power supply is official and strong enough, but a powered hub is the safe answer for multiple disks.

Buy Class 10 / U3, A1 or A2, from SanDisk Extreme, Samsung EVO/Pro, Kingston Canvas or similar. Avoid unbranded cards entirely.

Lifetime: a card writing constantly (a database, Docker logs, surveillance) can degrade in months. A card in a mostly-read workload lasts years. This is why the standard advice for anything permanent is: boot from NVMe/USB SSD, keep the SD card only as a recovery copy, and always keep backups of your configuration.

The Pi 5 has 2× USB 3.0 and 2× USB 2.0 (plus PCIe for NVMe). A powered USB hub lets you add many devices. The real limits are power (total USB current is bounded by the supply) and bandwidth (USB 3.0 ≈ 5 Gbps shared). For a media library, that is plenty — for a busy database server, it is not.

Remote access & networking

Three steps, and you never need a screen:

  1. In Raspberry Pi Imager, open settings (gear icon) and set hostname, username, password, Wi-Fi and "Enable SSH".
  2. Write the card, insert it, power on the Pi, wait 2 minutes.
  3. From your PC: ssh you@hostname.local (or the IP address). If you must enable SSH manually, create an empty file named ssh in the boot partition.

To see the graphical desktop remotely instead, use VNC or Raspberry Pi Connect, or install xrdp.

Yes, and you should do it in the safe order: Tailscale or WireGuard (private tunnel — nothing is exposed to the internet) → Cloudflare Tunnel (publish a web app without opening ports) → port forwarding (works, but exposes your home network; only do it for a specific service, with HTTPS and strong passwords).

Never expose SSH directly on port 22 to the internet without keys, fail2ban and a strong password policy.

Technically yes. Practically, your home internet upload speed, dynamic IP, power cuts and lack of DDoS protection are real limits. Many people host a personal blog or a small internal tool this way with great success (behind Cloudflare), and host anything with paying customers on a proper VPS. Use the Pi for staging and internal services — that is where it is unbeatable value.

A Pi running OpenWrt can act as a router, DNS server, VPN gateway, firewall or traffic monitor. It is a great addition to your router (Pi-hole, VPN, monitoring) and a legitimate option as a secondary router in a lab. As your only router, you need USB Ethernet adapters and you accept a single point of failure for the whole house.

Power & reliability

Pi Zero 2 W: 0.4–1.5 W. Pi 4: 2.5–7 W. Pi 5: 2.5–3.5 W idle, up to ~12 W under sustained load with peripherals. Running a Pi 5 24/7 at 5 W average costs roughly 3.6 kWh per month — around $1 in most countries. A desktop tower doing the same job would use 10–30× more. Test your own numbers with the power calculator.

Yes — this is one of the most common uses. Offices, factories and hobbyists run Pi-based systems for years. Do these four things: use the official power supply, keep it cool (below ~70 °C; heatsink or fan), boot from NVMe/USB SSD rather than microSD, and keep it away from dust and moisture. Then plan a periodic reboot schedule for kernel updates, not because it needs rest.

Modern Pi OS uses a journaled filesystem, so it usually recovers. But a power cut mid-write on a microSD card is the classic way to lose a system. Protect it with a small UPS ($40–$80) that can run a Pi for hours, enable a clean shutdown triggered by the UPS, and keep an image backup so restoring takes 10 minutes instead of a weekend.

For desktop use and especially for servers, yes — the official Active Cooler is $5 and drops sustained temperatures dramatically, keeping the CPU from throttling. A Pi 4 in a ventilated case with heatsinks is usually fine without a fan; a Pi Zero 2 W needs nothing at all.

As secure as you configure it — exactly like any Linux server. Minimum: change the default password, use SSH keys instead of passwords, enable automatic security updates (unattended-upgrades), and never expose services directly to the internet. Add fail2ban for SSH. Raspberry Pi OS ships with sensible defaults and no telemetry.

Learning, kids and jobs

It is arguably the best educational computer ever made. Scratch and Python are pre-installed, the Pi 500 is a kid-proof all-in-one, and the Foundation publishes free, classroom-tested project guides for every age. The key is to give them a goal — a Minecraft server for friends, a plant monitor, a robot — not just the board.

Pick something you will use daily, because that is what keeps you going when it breaks:

  • Pi-hole — 45 minutes, everyone in the house benefits
  • Media centre — 30 minutes, immediate payoff every evening
  • Home Assistant — one evening, genuinely changes how your house works
  • Blinking LED with a Pico — 5 minutes, teaches the electronics workflow

See 20 projects with part lists.

It can, if you treat it as a lab rather than a toy. The employable paths it feeds directly are Linux/DevOps administration (Docker, nginx, systemd, networking), IoT and embedded development (GPIO, I²C, SPI, MicroPython), edge AI (model deployment, computer vision) and industrial automation. What matters in interviews is that you can describe something you built, broke, fixed and measured — a Pi gives you that story for $55.

Yes — that is exactly what the virtual machine guide is for. You can install Raspberry Pi OS on your existing PC for free, learn the desktop, the terminal, SSH, servers and Docker, and only buy a board when you need GPIO, cameras or a permanent always-on machine.

Speak the language

Plain-English glossary

Every term you will meet in your first month, explained in one line each.

TermWhat it means
SoC"System on a chip" — the single chip containing the CPU and GPU. On the Pi 5 it is the BCM2712.
GPIOGeneral-purpose input/output — the 40 pins that let the Pi sense and control the physical world.
HAT"Hardware attached on top" — an add-on board that sits on the GPIO header (Sense HAT, AI HAT+).
HeadlessRunning the Pi with no monitor or keyboard, controlled entirely over SSH or a web interface.
ImagerThe official free tool that writes the operating system to a microSD card and pre-configures Wi-Fi, SSH and users.
microSDThe card that acts as the Pi's hard disk. Class 10 / A1 or A2, real brand, always.
NVMe / M.2Fast SSD storage attached through the Pi 5's PCIe connector — the biggest performance upgrade available.
PCIeThe high-speed expansion bus the Pi 5 exposes for NVMe and other add-ons.
SSHThe protocol for controlling the Pi from another computer's terminal: ssh user@host.
DistroA Linux "distribution" — an OS built from the Linux kernel plus software (Debian, Ubuntu, Raspberry Pi OS).
KernelThe core of the operating system that talks to the hardware.
Docker / containerA way to package an app with all its dependencies so it runs identically anywhere. The standard way to self-host.
Headless service / daemonA program that runs in the background, usually started at boot by systemd.
CronThe scheduler that runs your script at fixed times ("every night at 3 a.m.").
I²C / SPI / UARTThree standard ways chips talk to each other over short wires. Every sensor you buy uses one of them.
MicroPythonA tiny version of Python that runs directly on the Pico, with no operating system in between.
Firmware / bootloaderThe very first code the board runs before your OS starts.
PoEPower over Ethernet — power and network through a single cable, using a PoE HAT.
TOPSTrillions of operations per second — how neural accelerators like the AI HAT+ are measured (13 or 26 TOPS).
ThrottlingWhen the CPU slows itself down because it is too hot or underpowered. Check with vcgencmd get_throttled.
UndervoltageNot enough power from a cheap charger — the most common cause of mysterious crashes and SD-card corruption.
Compute ModuleA Pi without the usual ports, made for companies that build products around it.
