Don't know where to start?

A 90-day path from zero to "I built that"

  1. Week 1–2 · Get a working desktop

    Install Raspberry Pi OS with Raspberry Pi Imager (set username, Wi-Fi and SSH in the Imager settings — no screen needed). Learn the file system, apt, permissions, and how to connect with SSH.

  2. Week 3–4 · First finished thing

    Pi-hole or a media centre. Something that you will use every day, so it feels real. Learn how to read logs when it breaks.

  3. Week 5–8 · Automate something

    Home Assistant or a Python script on a schedule that emails/reports something to you. This is where you learn APIs and error handling.

  4. Week 9–10 · Add storage

    NVMe or SSD, Samba shares, rsync backups. Now you understand disks, filesystems and mount points.

  5. Week 11–12 · Go into the real world

    Breadboard, sensors, a Pico, a relay. Light a lamp from your phone. Then measure something: temperature, moisture, energy.

  6. After 90 days · Pick a speciality

    Home automation, self-hosting, robotics, networking, or edge AI. Each has a mountain of paid work behind it.
